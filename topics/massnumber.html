📘Lesson — Z and A: The Two Most Useful Numbers

Atomic number (Z)

The atomic number of an element is the number of protons in the nucleus of one atom of that element. It is written as Z.

  • In a neutral atom: number of protons = number of electrons. So Z tells us the number of electrons too.
  • Z is the identity card of an element. Change Z and you have a different element.
  • Hydrogen has Z = 1, helium Z = 2, lithium Z = 3, … and so on.

Mass number (A)

The mass number is the total number of protons and neutrons (the nucleons) in the nucleus of an atom. It is written as A.

and therefore  number of neutrons = A − ZA = number of protons + number of neutrons

💡
Careful: the mass number (A) is a whole number count of nucleons. It is not the same as the atomic mass you read in the periodic table (which may be 35.5 u for chlorine, because it is an average over isotopes).

The standard notation of an atom

The mass number is written as a superscript and the atomic number as a subscript on the left of the element's symbol:

example: carbon — ¹²₆CAZX   mass number A on top-left, atomic number Z below it

From the notation you can read everything at a glance:

¹²₆C

Carbon with mass number 12. Protons = electrons = 6, neutrons = 12 − 6 = 6.

²³₁₁Na

Sodium with mass number 23. Protons = electrons = 11, neutrons = 23 − 11 = 12.

💬Ask & Understand

Q1What is the atomic number of an element? Give its symbol.Very short answer▾

The atomic number is the number of protons present in the nucleus of an atom of an element. It is denoted by the symbol Z.

Q2Write the formula for mass number and define nucleons.Very short answer▾

Mass number (A) = number of protons + number of neutrons. The protons and neutrons present in the nucleus are collectively called nucleons.

Q3Pause & Ponder: An atom with an atomic number 26 has 56 nucleons. Find its number of electrons, protons and neutrons.Numerical · Pause & Ponder▾

Z = 26 → protons = 26. The atom is neutral, so electrons = protons = 26. Nucleons = mass number = 56. Neutrons = A − Z = 56 − 26 = 30.

Answer: protons 26, electrons 26, neutrons 30. (This element is iron, Fe.)

Q4Pause & Ponder: The nucleus of an atom contains 20 protons. If its mass number is 41, find the number of neutrons. / An atom has 18 neutrons and atomic number 17 — what is its mass number? / An atom ²³A has 11 electrons. Find the number of neutrons.Numericals · Pause & Ponder▾

(a) Neutrons = A − protons = 41 − 20 = 21.

(b) A = protons + neutrons = 17 + 18 = 35. (It is chlorine.)

(c) A = 23 and electrons = 11, so protons = 11. Neutrons = 23 − 11 = 12. (It is sodium, Na.)

📘Book Questions — Explained

1What are atomic number and mass number? Write the standard notation used to represent an atom, with an example.

Atomic number (Z) = the number of protons in the nucleus of an atom. Since atoms are neutral, the number of electrons equals the number of protons, so Z gives the number of electrons as well.

Mass number (A) = total number of protons and neutrons (nucleons) in the nucleus: A = number of protons + number of neutrons.

Notation: mass number A is written as a superscript on the top-left and atomic number Z as a subscript on the bottom-left of the element's symbol: AZX. Example: carbon has Z = 6 and A = 12, so it is written as ¹²₆C.

Short answer
2R3 Q11. An atom ⁷⁰X has 31 electrons. How many neutrons are there in its nucleus?

Mass number A = 70 and electrons = 31. Since the atom is neutral, protons = electrons = 31, so Z = 31. Neutrons = A − Z = 70 − 31 = 39.

Answer: There are 39 neutrons in its nucleus. (This element is gallium, Ga.)

Revise, Reflect, Refine · Q11
3R3 Q12. An atom has 79 protons and a mass number of 197. Calculate (i) the number of neutrons and (ii) the number of electrons.

(i) Neutrons = A − protons = 197 − 79 = 118.

(ii) The atom is electrically neutral, so electrons = protons = 79.

Answer: 118 neutrons and 79 electrons. (This element is gold, Au.)
